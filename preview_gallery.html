미리보기 페이지 — "활동 1개 = 사진 여러 장" 구조로 바꾸는 3가지 방식입니다. 실제 사진 대신 색깔 박스로 표시했습니다 (파랑 = 동계 MT 8장, 갈색 = 풋살 5장, 초록 = NeurIPS 3장).
클릭해보세요 — A·B는 클릭하면 큰 화면(라이트박스)으로 넘겨보기, C는 카드 클릭 시 바로 아래에 펼쳐집니다.

방식 A — 앨범 카드 + 라이트박스 슬라이드

활동 하나가 카드 하나. 대표 사진 + 제목 + 사진 개수 배지. 카드를 클릭하면 그 활동의 사진들을 큰 화면에서 ←→로 넘겨봄.
페이지가 짧고 깔끔하며, 활동이 쌓여도 카드만 늘어남. 단, 클릭 전에는 대표 사진 1장만 보임.

방식 B — 활동별 섹션 나열 (기존 홈페이지 방식의 개선판)

활동 제목 아래 사진이 전부 바로 보임. 스크롤만 하면 다 볼 수 있어 직관적 (기존 홈페이지와 같은 경험). 사진 클릭 시 크게 보기.
단, 활동과 사진이 많아지면 페이지가 매우 길어짐.

방식 C — 앨범 카드 + 클릭하면 아래로 펼침

평소엔 A처럼 카드 그리드라 짧고, 카드를 클릭하면 바로 아래에 그 활동의 사진 그리드가 펼쳐짐 (다시 클릭하면 접힘). A와 B의 중간.
