# SMOP Lab 홈페이지 관리 안내

고려대학교 스마트 모빌리티 운영·계획 연구실(SMOP Lab) 홈페이지의 관리 문서입니다.
논문·멤버·프로젝트·사진 등을 추가하거나 수정하는 방법을 정리했습니다.

- GitHub 저장소: <https://github.com/miinseoo/smop-lab>
- 공개된 사이트 주소는 저장소 **Settings → Pages** 에서 확인할 수 있습니다.

---

## 가장 먼저 알아야 할 것

**웹 개발을 몰라도 됩니다. 대부분의 수정은 `data/` 폴더 안의 파일만 고치면 끝납니다.**

홈페이지 화면(HTML)과 내용(데이터)이 분리되어 있어서, 논문을 추가하거나 멤버가 바뀌어도
`data/` 폴더의 파일에 내용만 적으면 화면에 자동으로 반영됩니다.
번호 매기기, 연도순 정렬 같은 것도 자동으로 처리됩니다.

> **각 데이터 파일 맨 위에는 작성법과 복사해서 쓸 수 있는 예시가 주석으로 적혀 있습니다.**
> 파일을 열면 제일 먼저 그 부분을 읽어보세요. 이 문서는 전체 지도 역할입니다.

## 데이터 파일별 요약

### 논문 — `data/publications/`

카테고리별로 파일이 나뉘어 있습니다. **본인 논문에 해당하는 파일만 열어서 추가**하면 됩니다.

| 파일 | 내용 |
|---|---|
| `international_journals.js` | 국제 학술논문 (학회 발표 논문 포함) |
| `domestic_journals.js` | 국내 학술논문 |
| `books.js` | 학술도서 (Book Chapter) |
| `patents.js` | 특허 |
| `publications.js` | **직접 수정하지 마세요.** 위 4개를 합쳐서 번호를 매기고 정렬하는 파일입니다. |

- **배열 어디에 넣어도 됩니다** — 연도 기준으로 자동 정렬됩니다.
- **번호(1, 2, 3…)도 자동**이라 신경 쓰지 않아도 됩니다.
- 저자 이름은 1저자만 `"성, 이름"`, 나머지는 `"이름 성"` 형식으로 적습니다.
  `"Seungmo Kang"` 또는 `"Kang, Seungmo"` 로 적힌 이름은 화면에서 자동으로 굵게 표시됩니다.

### 재학생 — `data/members.js`

- `role` 값에 따라 소속 그룹이 정해집니다: `postdoc` / `phd` / `phdcourse` / `masters` / `undergrad`
- **해당 그룹에 아무도 없으면 그 항목은 화면에 표시되지 않습니다.** 멤버를 추가하면 자동으로 다시 나타납니다.
- `links` 에는 개인 링크를 넣을 수 있습니다 (`linkedin` / `github` / `googlescholar` / `website`).
  없으면 `links: []` 로 비워두면 됩니다.
- `interest` 는 `"Research Interest:"` 접두어를 써도 되고 안 써도 됩니다 (화면에서 자동 처리).

### 졸업생 — `data/alumni.js`

- 학위별(연구교수 / 박사 / 석사 / 학사)로 자동 분류되고, 각 그룹 안에서 **졸업 시기가 이른 사람부터** 표시됩니다.
- `degree` 는 한글로 적습니다: `"박사"` `"석사"` `"학사"` `"연구교수"`
- `month` 를 적으면 화면에 `2026.02` 형태로 표시됩니다.
- 연구교수처럼 재직 기간으로 표시할 사람은 `yearLabel: "2013–2015"` 를 사용합니다
  (이 경우 `month` 는 적지 않습니다).
- `position`(현재 소속)과 `thesis`(졸업논문)는 **적을 것만 적으면 됩니다.** 없으면 그 줄을 지우세요.

### 연구 과제 — `data/projects.js`

- `startYear` 기준으로 자동 정렬되므로 배열 아무 위치에나 추가해도 됩니다.
- `period` 의 종료 연도가 올해 이후면 자동으로 **Ongoing**, 지났으면 **Completed** 로 표시됩니다.
- 관련 링크가 있으면 `link: "https://..."` 를 추가하세요. 카드에 **Link ↗** 버튼이 생깁니다.

### 갤러리 — `data/gallery.js`

- **활동 1개에 사진 여러 장**을 넣는 구조입니다.
- 배열 맨 앞에 넣은 활동이 화면 맨 위에 표시됩니다 (최신순으로 직접 정렬).
- 세로로 긴 사진은 **자동으로 인식**되어 세로로 긴 칸에 표시됩니다. 따로 표시할 필요 없습니다.

### 홈 소식 — `data/news.js`

- 배열 **맨 앞 4건만** 홈 화면에 표시됩니다.
- 가장 최근 소식이 제목·설명과 함께 크게 표시되고, 나머지는 한 줄 목록으로 나옵니다.
  목록을 클릭하면 그 소식이 큰 자리로 올라옵니다.
- 오래된 소식은 지우지 말고 아래에 그대로 두면 됩니다 (화면에는 안 나옵니다).

### 교수님 페이지 — `data/professor.js`

기본 정보, 약력(bio), 학력, 경력, 수상, 기타 경력(편집위원·위원회 활동)이 들어 있습니다.
형식은 파일 안의 주석을 참고하세요.

## 사진 넣는 법

사진은 용도별로 정해진 폴더에 넣고, 데이터 파일에 **경로를 적어야** 화면에 나옵니다.

| 용도 | 넣을 폴더 | 데이터 파일에 적는 경로 예시 |
|---|---|---|
| 재학생 | `images/members/current/` | `"images/members/current/홍길동.jpg"` |
| 졸업생 | `images/members/alumni/` | `"images/members/alumni/홍길동.jpg"` |
| 갤러리 | `images/gallery/활동폴더/` | `"images/gallery/2603_동계MT/26동계MT_1.jpg"` |
| 교수님 | `images/professor/` | `"images/professor/강승모.jpg"` |

사진이 아직 없으면 `photo: null` 로 두세요. 재학생은 회색 칸, 졸업생은 이름 이니셜로 표시됩니다.

> ### ⚠️ 확장자 대소문자를 꼭 확인하세요
>
> 파일이 `사진.JPG`(대문자)인데 데이터에 `사진.jpg`(소문자)로 적으면
> **내 컴퓨터에서는 잘 보이지만 실제 사이트에서는 사진이 깨집니다.**
> 윈도우는 대소문자를 구분하지 않지만 웹 서버는 구분하기 때문입니다.
>
> 파일 이름을 전부 소문자 확장자(`.jpg`, `.png`)로 통일해두는 것을 권장합니다.

갤러리 사진은 활동별로 폴더를 만들어 관리합니다. 폴더 이름은 `2603_동계MT` 처럼
**연도(2자리) + 순번(2자리) + 활동명** 형식을 쓰고 있습니다.

## 수정한 내용을 실제 사이트에 반영하기

파일을 저장한다고 사이트가 바뀌지는 않습니다. GitHub에 올려야(push) 반영됩니다.

**GitHub Desktop 등 프로그램을 쓰는 경우**
1. 변경된 파일 목록 확인
2. 아래 칸에 무엇을 바꿨는지 한 줄로 적기 (예: `2026년 논문 2편 추가`)
3. **Commit** 누르고 → **Push** 누르기

**명령어를 쓰는 경우**
```bash
git add .
git commit -m "무엇을 바꿨는지 한 줄 설명"
git push
```

> 푸시한 뒤 사이트에 반영되기까지 **1~2분 정도** 걸립니다.
> 바로 안 바뀌면 브라우저에서 `Ctrl` + `F5` (강력 새로고침)을 눌러보세요.
> 브라우저가 예전 화면을 저장해두고 보여주는 경우가 많습니다.

## 자주 하는 실수

데이터 파일은 **JavaScript 문법**이라 아래 규칙을 지켜야 합니다.
하나라도 어기면 **그 파일의 내용이 화면에 전혀 안 나올 수 있습니다.**

1. **쉼표(`,`) 빠뜨리기** — 항목과 항목 사이, 각 줄 끝에 쉼표가 있어야 합니다.
2. **따옴표 짝 안 맞음** — 글자는 반드시 `"..."` 로 감쌉니다.
3. **글 안에 큰따옴표 사용** — 제목 안에 `"` 가 들어가면 문법이 깨집니다.
   `“ ”`(둥근 따옴표)를 쓰거나 작은따옴표로 바꾸세요.
4. **숫자 칸에 글자 넣기** — `year`, `month`, `startYear` 는 숫자만 넣습니다.
   `year: 2026.02` 처럼 소수점을 쓰거나 `year: "미정"` 처럼 글자를 넣으면 안 됩니다.
   (월을 표시하려면 `month: 2` 를 따로 적으세요.)
5. **`|` 기호를 그대로 두기** — 주석의 `"박사" | "석사"` 는 "둘 중 하나를 고르라"는 뜻입니다.
   실제로는 `degree: "박사",` 처럼 **하나만** 적어야 합니다.

**수정한 뒤에는 반드시 브라우저에서 해당 페이지를 열어 확인하세요.**
내용이 통째로 사라졌다면 위 문법 실수 중 하나일 가능성이 높습니다.

## 화면 구조나 디자인을 바꾸려면

내용이 아니라 **화면 배치나 디자인**을 바꿔야 할 때만 아래 파일을 엽니다.

- **글꼴·색상 등 사이트 전체에 적용되는 것** → `style.css` 위쪽의 설정 부분
- **특정 페이지의 디자인** → `css/` 안의 해당 파일 (예: 멤버 페이지 → `css/members.css`)
- **특정 페이지의 화면 구조** → 그 페이지 폴더의 `index.html`

각 페이지의 `index.html` 아래쪽에는 데이터를 화면에 그리는 코드가 들어 있습니다.
**이 부분은 잘못 건드리면 페이지 전체가 안 나올 수 있으니, 수정 전에 파일을 복사해두는 것이 안전합니다.**

## 문제가 생겼을 때

| 증상 | 확인할 것 |
|---|---|
| 페이지 내용이 통째로 안 나옴 | 방금 수정한 데이터 파일의 쉼표·따옴표 확인 (위 "자주 하는 실수") |
| 사진이 깨져서 안 보임 | 파일 이름과 데이터에 적은 경로가 **대소문자까지** 똑같은지 확인 |
| 수정했는데 사이트가 그대로임 | 푸시했는지 확인 → 1~2분 기다리기 → `Ctrl` + `F5` |
| 논문 번호가 이상함 | 번호는 자동입니다. `publications.js` 를 직접 고치지 않았는지 확인 |
| 되돌리고 싶음 | GitHub 저장소의 **Commits** 목록에서 이전 상태를 확인·복원할 수 있습니다 |
